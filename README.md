# Autonomy Kernel

**An operating system for autonomous work.** A proposed standard for the runtime layer beneath AI agents: the floor that governs what an agent may do, records what it did, remembers what it learned, and can always be told to stop.

> There is no kernel yet. This is a proposal and a call for collaborators.

**Read the Hypothesis:** [autonomykernel.org](https://autonomykernel.org)

## Documents

- [The Autonomy Kernel Hypothesis](docs/HYPOTHESIS.md): the worldview and the boundary to build on.
- [Core Primitives](docs/PRIMITIVES.md): the objects the kernel governs and the two chains that bind them.
